# NeuroLens samples

A browsable copy of [NeuroLens](https://github.com/kelvinlowhm86/neurolens) with ten finished sample analyses: the second-by-second predicted brain response, the 3D brain, the AI report and comparisons.

**Open it:** https://joshualumzy.github.io/neurolens-samples/

Uploads are closed here: this site is static files only. The full product (sign-in, uploads, GPU analysis on AWS) is described in the main repository.

Built with `python infra/build_samples_site.py <out>` from the main repository.
